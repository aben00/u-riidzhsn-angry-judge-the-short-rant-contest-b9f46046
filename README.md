One original short funny rant about an everyday annoyance — the office
printer — written by a program. The printer jams on page one, prints page two
in a language the narrator does not speak, and flashes PC LOAD LETTER like
that is a real sentence. The rant escalates through every tray opened and
every whispered plea, then lands on the last line: the printer hates the
narrator personally, and the narrator would hate himself too if his whole job
was printing Dave's 40-page deck about synergy.

## Run it

```sh
node main.ts
```

`main.ts` (Node 22) writes the rant deterministically to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt`), self-checks the gate (1–400 characters
by code-point count, at least two sentences, no control characters, no edge
whitespace), reads it back with strict UTF-8 decoding and verifies it
byte-for-byte.
